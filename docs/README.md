# Documentation

Install `.[docs]`, then from the repository root:

```bash
mkdocs build --strict -f docs/mkdocs.yml
mkdocs serve -f docs/mkdocs.yml
```

`V1_PLAN.md` records the architect's intent, current scope and deferred questions.
Root-level design/release plans are marked historical. Current documentation
describes the production rate-based path, not the retained experimental modules.
